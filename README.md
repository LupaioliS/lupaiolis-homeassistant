# LupaioliS Home Assistant Add-ons

This repository contains custom Home Assistant add-ons maintained by LupaioliS.

It is intended to be used as a custom add-on repository in Home Assistant so you can install and update add-ons directly from the Add-on Store.

## Available Add-ons

### MetaPlants

Plant management add-on for Home Assistant.

Project folder:
- [metaplants](metaplants)

Addon documentation:
- [MetaPlants README](metaplants/README.md)

## Add This Repository to Home Assistant

1. Open Home Assistant.
2. Go to Settings -> Add-ons.
3. Open the Add-on Store.
4. Click the top-right menu (three dots) and choose Repositories.
5. Add this URL:
   - https://github.com/LupaioliS/lupaiolis-homeassistant
6. Confirm and refresh the store.
7. Install the add-on you want from this repository.
